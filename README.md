# 🧊 Fridge Inventory Manager

ระบบจัดการตู้เย็นและวันหมดอายุ เขียนด้วยภาษา Python (CustomTkinter + Pillow)
โปรแกรมนี้ประยุกต์ใช้อัลกอริทึมการเรียงลำดับและการค้นหาข้อมูล (Data Structures & Algorithms)

## 🛠️ อัลกอริทึมที่ใช้ในโปรเจกต์
- **Bubble sort**: เรียงของตามวันหมดอายุให้ใกล้หมดอายุอยู่หน้าสุด
- **Insertion sort**: แทรกวัตถุดิบใหม่เข้าตำแหน่งที่เหมาะสมตามวันหมดอายุ
- **Selection sort**: คัดแยกเนื้อสัตว์ลงชั้นล่างสุดตามความแรงของกลิ่น
- **Merge sort**: รวมรายการวัตถุดิบจากทุกตู้เย็นเข้าด้วยกัน
- **Sequential Search**: ค้นหาขนมโดยการเปิดดูทีละช่อง
- **Binary Search**: ค้นหาชื่อวัตถุดิบอย่างรวดเร็วในรายการที่เรียงลำดับแล้ว
